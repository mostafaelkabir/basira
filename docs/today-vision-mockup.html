B The strip owns the timer

Built from the existing active_timers in the day workspace. Works for tasks, tickets and habits once the timer context calls the unified switch endpoint. The floating widget disappears on Today.

C A denominator, finally

Three new settings: day start, day end, buffer. Over-capacity turns the bar amber and says by how much. Today's planned duration is a day block, not the ticket's lifetime estimate.

E Timeline, not a list

Start and end, a thin progress bar, a now marker, labelled open gaps, and overlap warnings from the existing conflict preview. Every source gets the same three actions.

F Carry is a decision

Nothing carries forward silently. Carry, drop or reschedule each item; the carried list becomes tomorrow's first suggestion group. Four-month-old "carried over" labels stop existing.

Plan Suggestions you can face

Grouped by reason, capped per group, stale overdue collapsed under Older, and a Not today action. Planning opens beside the plan so you can see the day while you build it.

D Habits stay light

One row of chips with a count and a daily check mark each. A habit's usual time shows on its chip as a hint. Habits never appear on the timeline and are never timed; the schedule below is for work only.
